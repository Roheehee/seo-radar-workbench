新词雷达：免费 SEO 工作台

【工作台入口】
双击“打开工作台.bat”，会启动本地服务并打开 http://127.0.0.1:8765。
工作台支持：监测总览、线索筛选、收藏与备注、写作状态、CSV 导出、历史报告、监测设置。
新增用户意图识别：线索列表显示可能意图、置信度、依据摘要和适合的页面；点击名称查看完整证据、页面内容建议及待验证项。
支持按意图筛选，线索和选题 CSV 均包含意图分析字段。已有历史报告打开时自动分析，无需重新采集。
分析在本地按规则完成，不调用付费服务，也未查询搜索结果；项目描述只作为上下文，不当作用户搜索证据。
点击“开始免费采集”后可以切换页面，完成后数据自动刷新。
设置里的数据源开关和 GitHub 门槛在下次采集生效。
收藏保存在 state/workbench-saved.json，设置保存在 config.json 和 state/workbench-settings.json。
服务仅监听本机地址；关闭网页不会停止服务，电脑重启后需再次双击入口。
不要同时使用工作台和旧的免费日报入口运行采集，以免历史快照并发写入。

【原有日报入口】

双击“运行免费日报.bat”，等待完成，浏览器会打开本次报告。
双击 latest-report.html 可以查看最近一次报告。
每次报告和日志保存在 reports/日期时间/，历史快照保存在 state/。
建议每天手动运行一次；不要删除 state，否则会重新建立基线。

默认启用：GitHub 爆发仓库、Hugging Face 热门变化，以及 ai-bot.cn、opentools、futurepedia 的 sitemap。
第一次运行主要建立基线；部分网站可能因网络或访问限制读取失败，报告会注明。
首次运行会从 config.free.example.json 创建 config.json，默认为中文报告、空已覆盖关键词。
原始完整示例仍保留在 config.example.json。

免费入口明确跳过所有付费模块，不会因以后设置 API Key 而自动启用付费调用。
完整关键词分析尚未启用，需要配置 AISA_API_KEY；GoAnyAPI 为可选增强服务。
此入口未设置后台计划任务，也不自动发邮件。

命令行运行（不自动打开报告）：
python -X utf8 run_free.py --no-open
搜索意图研究（2026-11-26 更新）
侧栏「搜索意图研究」用于保存你录入的搜索证据。公开版本不包含任何客户或品牌研究数据。
点击查询词，可查看实际观察、具体任务推断、页面规划、原始证据链接、同名结果排除理由与限制。
样本为精选搜索结果，不是完整前十排名；未取得搜索量。官网文案仅作身份和公开内容佐证，不代表功能或价格已经实测。
「研究新关键词」可打开百度，再人工录入结果标题、链接、摘要、页面类型和产品身份。保存后用本地规则推断，数据保存在 state/intent-research.json；不会调用付费 API，也不会自动联网抓取搜索结果。
新增研究按完整查询词精确关联线索，其他查询不会借用其搜索证据。没有搜索证据的项目名显示「待核验（仅项目名）」。
「导出研究 CSV」包含意图、页面建议、日期、样本限制与证据链接。内置样本位于 workbench/research-seed.json，人工研究记录单独保存。
